## Body

Hello,

I am the author of **Star Icons**, a free, open-source (MIT) plugin for the
Obsidian note-taking app. It lets users browse icon sets and apply them to
files, folders and tabs. The source is at
https://github.com/Stef4678/star-icons.

We bundle **Remix Icon 4.9.1 (3,078 icons)** as one of ~34 icon packs inside
the plugin. For technical embedding, the SVG files are converted to compact
JSON: XML comments/declarations are stripped and the markup is re-wrapped
into a standard shell (fill/stroke attributes). No icon is visually altered.
The plugin is free, is not an icon marketplace, and does not sell icon assets;
Remix Icon is one component among many, not the primary value of the product.
Copies of the license and notices are kept in the repository
(`licenses/remix-icon-1.0.txt`, `THIRD-PARTY-NOTICES.md`), and we use the
suggested attribution "Icons by Remix Icon (https://remixicon.com)".

Our question concerns the **Remix Icon License v1.0**:

- Section 2.3 permits distribution "as part of a larger work" — which we
  believe covers bundling the icons inside a plugin.
- Section 3.2 prohibits using the icons to "create, distribute, or sell a
  competing icon library or icon set".

Since Star Icons is an icon *manager* (a tool for applying icons in a
note-taking app), not an icon *set* offered for sale, we believe §3.2 does
not apply — but we would like **written confirmation** that bundling Remix
Icon in this plugin is permitted under the license.

We are happy to adjust attribution, notices or distribution on your advice.

Thank you,
