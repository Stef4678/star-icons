Hello,

I am the author of **Star Icons**, a free, open-source (MIT) plugin for the
Obsidian note-taking app. It lets users browse icon sets and apply them to

https://github.com/Stef4678/star-icons.

We bundle **Unicons 4.2.0 (line, solid, monochrome and thinline — 1,919
icons)** as part of ~34 icon packs inside the plugin. For technical embedding,
the SVG files are converted to compact JSON (XML comments/declarations
stripped, markup re-wrapped into a standard shell); no icon is visually
altered. The plugin is free, does not sell icon assets, and is not an icon
marketplace or a competing icon service.

Inc.):

1. **"Similar or competing service" clause** — the license says files may not

   bundling Unicons this way is permitted?
2. **Attribution for converted files** — the license states that assets you
   did not originally design but "edited in some way" must attribute the
   original creator when republished. Our conversion is purely technical
   (format/encoding, no visual change). Do you consider this an "edit" that
   requires attribution, and if so, what exact credit line do you require?

We already attribute IconScout and keep the license text in the repository
(`licenses/iconscout-simple.txt`, `THIRD-PARTY-NOTICES.md`), and we never
resell or republish the icons as a standalone set.
