## Compliance notes

- **Remix Icon (Remix Icon License v1.0):** the npm package ships a custom
  license dated January 2026 (its package metadata still lists Apache-2.0 —
  the file in the package is authoritative). Section 3.2 prohibits using the
  icons to create or distribute a *competing icon library*. Review this
  restriction before redistributing the set; §5 requires including a copy of
  the license when distributing the complete library or substantial portions
  of it.
- **Unicons (IconScout Simple License, © 2022 Design Barn Inc.):** allows
  commercial use and modification, but republishing edited assets requires
  attributing the original creator, assets may not be resold/republished as a
  separate entity, and files may not be collected to build a similar or
  competing service (`licenses/iconscout-simple.txt`).
- **Boxicons:** the shipped LICENSE is MIT, while the npm metadata lists
  CC BY 4.0 / OFL 1.1 as alternative terms.
- **Font Awesome Free:** the icon fonts are under SIL OFL 1.1 and the code
  under MIT; the SVG icons are CC BY 4.0. Brand icons (for example GitHub,
  Apple, Microsoft, Docker, OpenAI) are additionally subject to the trademark
  rights of their owners.

## Emoji fonts

The Animals, Nature & Flowers and Science packs render Unicode emoji
characters with the user's operating-system emoji font. Star Icons does not
bundle or redistribute emoji font files, so no emoji font license is shipped
with the plugin; the applicable license is that of the user's OS font.
